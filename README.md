## Local preview

Open `index.html`, or:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

GitHub Pages deploys from `main` via Actions (repository root). Live intro video: `assets/raven-flock-intro.mp4` (`?v=4`).
